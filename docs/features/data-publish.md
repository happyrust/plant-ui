# 三维数据提资

## 它是什么

**提资**（见 `CONTEXT.md`）：把人工挑选元素的三维数据交给数据中心的一次操作，按专业成包提交，经 rs-server 转数据中心。任务窗里的五个类别，前四个（工艺 / 电气 / 仪控 / 通风）是真提资；第五个「房间」实为**管道房间号查询**（见 `CONTEXT.md`），只是寄居在同一扇窗里，概念上不算提资（2026-08-05 拷问定案）。

## 行为边界

- **只读模型本体**：从模型树或三维视图的当前选中里逐个「添加」元素（按参考号去重），不改动任何模型数据，也不参与增量更新与任务队列。
- **提交是异步单发**：确认后经宿主发给 rs-server（默认 `127.0.0.1:9099`，可在设置里改，环境变量 `PLANT_DATA_API_URL` 可覆盖），60 秒超时，结果只落日志一行（成功带响应体原文，失败带错误）。**没有进行中 / 成功态的窗内呈现**。
- **四个专业类别共用一个数据中心契约**：`{refnos[], title, create_rvm_relations: true, b_first_time_design}`；`b_first_time_design` 由设计阶段（初设 / 施设）折算。
- **房间号查询发的是名称不是参考号**（`[{name, position: []}]`），查询结果目前同样只落日志，没有结构化呈现。
- **预览只是表单回显**：不发请求、不校验服务可达。

## 入口与状态

- 入口有两个，都在命令栏「创建」菜单里：
  - 「三维数据接口」：旧入口，不检查数据新旧。菜单项、窗口与行为保持不变（2026-11-26 用户定）。上面「行为边界」说的是它。
  - 「三维数据提资」：新入口，带提资前检查，见下一节。
- 状态：旧入口已实现（无画板；代码先行）。新入口已实现到「按库放行」这一档（画板 S15 族，ADR-0036）；按单元放行与优先增量更新等 gen-model，真服务端验证见计划。

## 新入口：三维数据提资（带提资前检查）

与旧入口打同一组 rs-server 接口，表单、预览子窗、确认删除子窗也是同一套；多出来的是提交之前的一道检查（词汇见 `CONTEXT.md`：提资前检查、更新到最新、放行、更新不了）。

- **查什么**：只查提资元素所在的库。每个库一行：文件最新保存的时刻、数据水位、状态（已是最新 / 落后 N 次保存 / 需初始化 / 在排或在跑 / 更新不了 / 没查成）。检查只读，不排任何任务。
- **什么时候查**：打开、提资元素有增删、点「重新检查」、队列里这几个库的活有变化、库登记表上这几个库的水位有变化（开着窗的时候文件又来了新保存，窗口自己会变回「不是最新」）、更新落定之后、点「提交」时；有库在排、在跑或模型在追赶时每 3 秒一次。
- **硬拦**：检查没放行，「提交」就灰着，没有绕过。确实要照交的，走旧入口。
- **更新到最新**：一枚按钮把落后的库排上增量更新、把需初始化的库排上首次导入（增量在前），进度画在库行上，落定后自动重新检查。它只排提资元素所在的库，队列暂停时不替人恢复。
- **更新不了的库**（已阻断含文件回退、够不着、不在范围、上次更新失败已停、已是最新却缺行、模型没追平又没有任务在跑）：行上说出路；主操作换成「移出这 N 个元素」。文件里已经删掉的元素同样要移出。
- **判不了就不拦**：模型服务没有检查接口（老版本）或不入库（读透）时，检查整块不画，只留一句话（「这台模型服务不支持提资前检查」），提资照旧。连不上或查询失败不算判不了——那是「没查成」，要拦。
- **窗口**：可以拖；窗口头上「收成一条」，收起来的那一条上有「添加当前选中」，方便去模型树或三维视图里选元素。表单有「设计阶段」分段选择。提交结果除了进日志，也写在窗口底部。
- **与旧入口的关系**：两扇窗共用预览与确认删除两扇子窗，所以不同时开着，后开的顶掉先开的；旧窗一次提交在途时新窗不顶它。
- **今天还差的**（等 gen-model，逐格见 `design/DATA-PUBLISH-FIELD-MAP.md`）：按交付单元放行、优先增量更新（提到队首、提资单元先生成）、暂停时只放行这几个库、落后时数据水位停在哪一次保存的时刻。房间归属还在重算时今天只提醒、不拦。
- **不接后端怎么看**：`rs-plant --gallery=s15` 把这扇窗的某个形态直接摆出来（另有 `s15-a` / `s15-import` / `s15-b` / `s15-stuck` / `s15-unknown` / `s15-unsupported` / `s15-empty` / `s15-bar`，后缀 `@dark` 换深色）；整条路在模拟模式（`PLANT_UI_SIM=1`）里走得通。目检记录与截图：`docs/evidence/2026-11-26-data-handover-sim-inspection.md`。

## 已知问题与待办

| 问题 | 事实 | 去向 |
|---|---|---|
| 旧入口的表单没有设计阶段选择器 | `design_phase` 字段存在、永远是默认「初设」，只在预览里展示 | 新入口已有「设计阶段」分段选择；旧入口按「保持不变」不补 |

| 名称不统一 | 旧入口窗口标题「三维数据接口」、菜单项同；模块叫 data_publish | 新入口已叫「三维数据提资」（模块 data_handover）；旧入口按用户要求保持原名，两个入口收敛与否另议 |
