# 三维数据提资

## 它是什么

**提资**（见 `CONTEXT.md`）：把人工挑选元素的三维数据交给数据中心的一次操作，按专业成包提交，经 rs-server 转数据中心。任务窗里的五个类别，前四个（工艺 / 电气 / 仪控 / 通风）是真提资；第五个「房间」实为**管道房间号查询**（见 `CONTEXT.md`），只是寄居在同一扇窗里，概念上不算提资（2026-08-05 拷问定案）。

## 行为边界

- **只读模型本体**：从模型树或三维视图的当前选中里逐个「添加」元素（按参考号去重），不改动任何模型数据，也不参与增量更新与任务队列。
- **提交是异步单发**：确认后经宿主发给 rs-server（默认 `127.0.0.1:9099`，可在设置里改，环境变量 `PLANT_DATA_API_URL` 可覆盖），60 秒超时，结果只落日志一行（成功带响应体原文，失败带错误）。**没有进行中 / 成功态的窗内呈现**。
- **四个专业类别共用一个数据中心契约**：`{refnos[], title, create_rvm_relations: true, b_first_time_design}`；`b_first_time_design` 由设计阶段（初设 / 施设）折算。
- **房间号查询发的是名称不是参考号**（`[{name, position: []}]`），查询结果目前同样只落日志，没有结构化呈现。
- **预览只是表单回显**：不发请求、不校验服务可达。

## 入口与状态

- 入口：命令栏「创建」菜单 →「三维数据接口」（菜单项与窗口标题仍是旧名，待收敛到「三维数据提资」）。
- 状态：已实现（无画板；代码先行）。
