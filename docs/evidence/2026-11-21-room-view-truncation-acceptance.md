## 1. 挑的房间

### 点断口、点墙外那截（完成定义第 5 条）

M5 之后补验：19:22 用同一个构建、同一套现场和临时设置重新起桌面端，L507 在 19:24–19:26、R286 在 19:29–19:32 点。
每间房三格同一机位、同一个点：截断开点断口、截断关点墙外那截、截断开再点同一点。每格下面裁了属性栏头（类型与名称、
参考号、房间），蓝圈是点的位置。这个应用点空处不清选中，所以「截断开 · 同一点」那一下之前先选好一件别的，
好分清「没点中」与「点中了管子」。

- **点断口选中的是被截的那一件**：断口与补出来的兄弟段都抄被截那件自己的 `ModelPickTarget`（`room_clip.rs` 的 `cut`）。
  直管件有自己的参考号，点断口选中直管件本身，与点它的管身是同一件；分支下没有参考号的直段以 BRAN 渲染，点断口选中的才是 BRAN。
  三间房四格之和都等于直管件数（§2），截到的全是直管件，所以「点断口选中 BRAN」在这套数据上看不到，只有单测
  （`selecting_the_branch_highlights_every_piece_but_not_the_caps`）。
- **旋转中心没单独看**：拖动起手与滚轮缩放取 `surface_hit` 的落点作旋转中心，与拾取是同一条射线、同一个过滤
  （只打可见的 `ModelPickTarget`）。
- **整件在房外、被藏起来的那种没点**：R286「房间外 1 段不画」的那一件没找到，多半在白墙后面；12 件逐件排查收益不大。

## 4. 两套主题下的剖切色

剖切色是固定的洋红 `#D946EF`（`room_clip.rs` 的 `SECTION_COLOR`），不跟主题走。E3D 外观的视口底色是 E3D 自己的灰到白渐变，也不跟主题；
web PBR 外观的底色跟主题。同一机位、截断开着，拍了亮色 / 深色 × E3D / web PBR 四组（`theme-section-colour.png`）：
四组里断口都一眼能认出来——E3D 下是浅灰构件上的洋红，PBR 下是浅褐构件上的洋红，深色主题的深蓝灰底上一样清楚。拍完设置改回了亮色 + E3D。

### 房间体缺一块面板网格（完成定义第 7 条）

M5 之后补验，19:51–19:57 用上面同一个包、同一套现场，只在浏览器端做（桌面端要接管鼠标键盘，没做）。缺网格这一档两端是同一段代码：
视口建房间体时有面板网格加载失败，就回「不可用」并报缺几块（`room_clip.rs` 的 `settle_solid`）；两端只差网格从哪来，
桌面端读本地网格目录，浏览器端向站点资产根下的 `meshes/` 取。

造缺口的办法：测试站点改用 `.agent-tmp/room-trunc/serve-web-dod7.py`（不入库），`config.json` 的 `assets_url` 指回站点自己的
`/dod7-assets`，那里把请求原样转给模型服务的 `/assets`，只有 L507 唯一那块在册面板（pe:24381_5090）的网格
`e3d_baked_v2_ffebb8a387b6f6d68ce994c7049f061cdf4dc19220a225c4c71f78c9ac83e6d9.mesh` 回 404。浏览器端取网格遇到 404 不重试
（`mesh_fetch.rs`），这块面板就一定缺。e2e 包和它的网格目录都没动。

## 6. 顺带看到的（都不在本次范围，未动）

- **伸出房间的整件不是漏截。** R320 顶上伸出房间的竖杆是设备的圆柱基本体（CYLI 24381/159633，属 EQUI「/Copy-of-1RCS082LN-下段」，
  高 6880 mm），R286 左下伸出房间体的白色块是墙（STWALL）。截断只管直段与直管件（TUBI、FTUB / STRT），别的成员整件画，通用剖切另立（计划 §八）。
- **房间视图里另装一间房，新装的不受隔离。** 在 L507 的房间视图里用房间树给 R286「加载模型」：新装的 22 个模型照常显示，房间视图仍是 L507。
  计划只约定取回工作 / 重装之后重新隔离（宿主的 `reapply_room_view_after_reload`），这条路径没覆盖；要不要跟进留给计划负责人。
- **R320 的「未能截断 2 段」** 没逐件查是哪两件。同一套判法下 R220 那 2 件是六根短杆组成的 FTUB、最外一根在房外（ADR-0028 修订第 5 条），
  可能是同类，没核实（R220 复核后是 5 件，见 §2 末）。
- **E3D 外观的图里构件没有黑色边线**：本机 Vulkan + GPU 间接绘制下 prepass 不落笔，是已知的老问题（`docs/evidence/2026-10-22-e3d-look.md` §4.4），
  与本次无关。
- **退出房间视图不写日志**，只能看画面判断。

- 完成定义第 5 条只实机验了「点不到墙外那截」（§3 末，L507 与 R286）。「点断口选中所属 BRAN」这套数据截到的全是直管件，

  `surface_hit`，没单独看；整件在房外、被藏起来的那种没找到实例，没点。
