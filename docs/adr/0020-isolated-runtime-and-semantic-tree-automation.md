# ADR-0020：测试运行期隔离设置并按语义树项自动化

状态：Accepted（2026-08-14）

关联：0011（任务队列进度）、0014（祖先路径定位）、0018（切换工程重启客户端）、
0019（保存窗口展示）。

## 背景

桌面测试过去从可执行文件旁读取开发者设置，并按 AccessKit 中第一条包含名称的文本点击。
命令历史、属性面板或旧设置都可能让测试命中错误对象。

## 决策

1. `PLANT_UI_SETTINGS_FILE` 显式指定设置文件时，只从该绝对路径读写；未指定时保持现有路径。
2. 资产根继续由 `PLANT_ASSET_ROOT` 解析，测试工作目录由启动器固定，不复制运行期资源。
3. 模型树真实行公开稳定的 tree-item role、refno 与当前名称；自动化同时匹配 role 和 refno。
4. 增量验收等数据任务、模型任务、pending 与视图刷新代次全部收口后再定位和断言。

## 后果

- 生产设置优先级不变；测试设置与开发者状态隔离。
- 重命名、增加和删除后的树缓存与选择状态成为显式验收面。
