# 直段截断改写实例变换，不做着色器剖切

房间视图要只画直段在房间体内的那一截（`CONTEXT.md`「直段截断」）。直段是共享单位原型（圆管 `CylinderV3`、
矩形风管 `BoxV1`）按实例变换摆放的，截断在几何上就是把原型的局部 Z 区间重映射到保留的那一段。
**决定：只改直段网格那一级子实体——保留段重映射局部 Z，整段在外的子实体隐藏，一段直段留下几截就补几个
同原型的兄弟实体；断口是同一原型压成 2 mm 的薄片、刷剖切色。不引入新材质或着色器，也只截直段，不剪别的构件。**
模型根的变换、可见性与包围盒都不动，eye（ADR-0016）、隔离快照与 `view.bounds` 照旧；拾取是主世界三角形上的
CPU 射线，改了变换、藏了子实体，墙外那截自然点不中。

## Considered Options

- **着色器按房间体 discard（剖切盒式）**：拾取与旋转中心照样落在看不见的那截上；上万个网格都要换扩展材质；
  切开的管子是空心的，封口得另上模板缓冲；离屏 + WebGL2 上自定义材质已经整段不画过一次（无效直段因此退回
  `LineList`）。被否。
- **CPU 布尔切网格**：精确，但要为每段生成独立网格，打散原型共享与合批，开关一次就要重建上千个网格。被否。

## Consequences

- 只截「沿局部 Z 的棱柱」：原型的 z 范围从网格自己读（`CylinderV3` 是 [0,1]，`BoxV1` 居中 [-0.5,0.5]，
  写死会把风管截偏半根）；顶点不全落在两个端面上的网格不截，计数上报。
- 斜穿墙时断口垂直于管轴，截在轴线与房间体表面的交点，墙面两侧各差 r·tanθ。
- 型钢、桥架、设备要一起剪是另一个功能（剖切盒），设计稿 HUD 上的「剪裁」格留给它。
- 计划：`docs/plans/2026-09-29-room-view-tube-truncation.md`。
