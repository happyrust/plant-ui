# 模型树 eye 反映实际渲染结果

ADR-0010 把模型树 eye 定义成最后一次显示 / 隐藏指令。模型加载改成异步查询与增量
mesh 装载后，这个定义会让图标抢在画面前变化，并在查询失败或 mesh 缺失时说谎。

eye 改为读取 View3d 回执的实际结果：

- 指令方向单独暂存，只用于查询回来后的最终方向和加载途中再次点击。
- 新模型等 mesh 全部成功或失败后回执；已加载模型等可见性命令落到实体后回执。
- 几何行按自己的结果显示；容器行聚合已经解析并缓存的实际模型范围。
- 尚未单独解析范围的子行继承最近祖先的实际状态；子行一旦查询出自己的范围、明确
  查空或查询失败，就改用自己的结果。
- 全显示、全隐藏、未加载之外增加半可见：后代状态混合，或可见模型只有部分 mesh
  加载成功。
- 半可见节点点击后显示全部；查询或加载期间 eye 保持原状态。

`HideAll` / `ShowAll` 仍只作用于已经进入场景的模型。eye 查询只消费数据库里的既有
模型与 `assets/meshes`，不调用模型生成接口。

本决定取代 ADR-0010 中“eye 反映最后一次指令”的部分；“未加载不是隐藏”仍然成立。
