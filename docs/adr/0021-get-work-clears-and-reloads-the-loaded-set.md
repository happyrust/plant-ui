# 取回工作清空三维并重装已加载集

CONTEXT.md 给「取回工作」下的定义是：把库里此刻的样子取到界面上来，模型树与**已加载
的**三维模型都算在内，不应用任何数据。实现偏离了这条定义：三维每次都整场重查全部
SITE 根，回包到手才原子替换。后果是冷查询那十几秒里旧几何一直挂在屏上冒充新数据，
落地后又把全厂元素一律点亮、把相机拉去看全场——内容刷新了，用户的视野被重置掉。

取回工作的三维半边改为「点击即清场、只重装已加载集」：

- 点菜单那一刻就清空场景并复位宿主台账，eye 全部回「未加载」，与 ADR-0016 一致：
  加载途中不抢说「已显示」。空场景是诚实态，旧几何本来就不可信。
- 清场前拍一份快照：场景里存在的每个模型 refno 配上取回前的方向（用户最后一次指令
  优先于 View3d 实际回执）。快照只记第一次，重试与欠账补载都按同一份回放，成功落地
  才消费。
- 重查范围就是快照里的那批模型，不再是全部 SITE 根。新增元素只进树、三维保持未加载
  ——「未加载」与「已隐藏」仍是两回事（ADR-0010）；库里删掉的自然消失。
- 重装落地后按快照回放显示 / 隐藏，相机不动。自动取景只留给落进空场景的那一批。
- 重载在途时后台又出现更新任务，查回来的结果不再整包丢弃：它比空场景新，也比旧几何
  新，一律上屏。上屏后若又有新保存落库，仍走既有的「自动刷新只换树 + 日志提示再点
  取回工作」。欠账机制只服务查询失败：场景保持清空、给红字，队列空闲后自动补一次。

模型树的取回行为不变：就地刷新，展开、选中、滚动全部保留。
